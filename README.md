# Power BI Sales Dashboard

An interactive global sales performance dashboard built using Power BI Desktop, designed to analyze trends, geographic distributions, and detailed transaction data.

## Project Overview
- **Data Cleaning & Transformation:** Performed using Power Query to verify data types and structure the dataset.
- **Visualizations:** 
  - **Line Chart:** Displays sales trends over time (by Year/Month).
  - **Map Visual:** Visualizes sales performance geographically across different countries.
  - **KPI Cards:** Highlights high-level metrics like Total Sales.
- **Interactivity:** Includes dynamic slicers for **Product Line** and **Region**, plus custom drill-through navigation to a **Transaction Details** page.

## Files Included
- `Newproject.pbix` - The main Power BI report file.
- `sales_data.csv` - The source sales dataset.

## How to View
1. Clone or download this repository.
2. Open `Newproject.pbix` using Power BI Desktop.
